Method

About this atlas

An atlas shows what exists and how it connects. It does not tell you what to use.

What is in it

282 tools in 21 categories, 53 groups of alternatives, 203 “builds on or pairs with” links and 6 starting stacks. Every tool links to its own site.

What it does not claim

  • No rankings, no popularity figures, no version numbers. Those change faster than a hand-kept atlas can follow, and a ranking would turn a map into an argument. The data check refuses descriptions that contain them.
  • Descriptions are written from general knowledge. Each is a plain statement of what the tool is. They are not copied from the tools’ own pages, and a project may have changed what it does since. The official site is always the authority.
  • Relations are editorial. “Alternatives” means the tools do the same job. “Builds on or pairs with” is a judgement about common use, not a dependency graph.
  • Stacks are starting points. They are one reasonable combination, not the right one for every project.

How it stays honest

npm run validate checks that every id is unique, every relation points at a real tool, every description is a short plain sentence, and no description makes a numeric or superlative claim. npm run links asks each tool’s website whether it still answers. Sites that refuse automated requests are reported, not silently passed.

Adding a tool

Add one line to a file in src/data/, add its relations in src/data/relations.ts, and run the validator. The pages, the map, the search and the graph all read the same data.

Built with

Astro with content generated from typed data files, and two small Preact islands (search and graph). Every page except those two ships no JavaScript.
