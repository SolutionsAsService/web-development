Testing

Unit, component, end-to-end, mocking and visual testing.

  • JestA JavaScript test framework with assertions, mocking and snapshots in one package.
  • VitestA Vite-native test runner with a Jest-compatible API.
  • PlaywrightEnd-to-end browser testing across Chromium, Firefox and WebKit.
  • CypressA browser-based end-to-end and component testing tool with an interactive runner.
  • Testing LibraryUtilities for testing UI the way users interact with it, for many frameworks.
  • MochaA flexible JavaScript test runner that leaves assertions to other libraries.
  • SeleniumThe long-standing browser automation project behind the WebDriver standard.
  • WebdriverIOA browser and mobile automation framework built on WebDriver and BiDi.
  • PuppeteerA library for controlling Chrome and Firefox programmatically.
  • StorybookA workshop for building, documenting and testing UI components in isolation.
  • Mock Service WorkerAPI mocking at the network level for tests and development.
  • node:testThe test runner built into Node.js.
  • bun testThe Jest-compatible test runner built into Bun.
  • k6A load-testing tool scripted in JavaScript.
  • ChromaticVisual regression testing and review for Storybook components.
  • jsdomA JavaScript implementation of the DOM for running browser code in Node.js.
  • happy-domA lighter DOM implementation for test environments.
  • FakerGenerates realistic fake data for tests and seeds.
