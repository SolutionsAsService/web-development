Serve and store

Databases, ORMs and search

Where data lives and how code reaches it.

  • PostgreSQLAn advanced open-source relational database.
  • MySQLA widely deployed relational database.
  • SQLiteA self-contained SQL database stored in a single file.
  • MongoDBA document database storing JSON-like records.
  • RedisAn in-memory data store used for caching, queues and sessions.
  • PrismaA TypeScript ORM with a schema file and generated client.
  • Drizzle ORMA lightweight TypeScript ORM that stays close to SQL.
  • TypeORMAn ORM for TypeScript and JavaScript using decorators.
  • SequelizeA promise-based ORM for Node.js.
  • KyselyA type-safe SQL query builder for TypeScript.
  • SupabaseA Postgres-based backend platform with auth, storage and realtime.
  • FirebaseA Google platform with databases, auth, hosting and functions.
  • NeonServerless Postgres with branching.
  • TursoA hosted database platform built on SQLite technology.
  • ConvexA reactive backend with a database and server functions in TypeScript.
  • PocketBaseA single-file backend with a database, auth and an admin UI.
  • AppwriteAn open-source backend platform with databases, auth and storage.
  • PlanetScaleA managed database platform based on Vitess and MySQL.
  • MeilisearchA fast open-source search engine.
  • TypesenseAn open-source search engine tuned for instant search.
  • AlgoliaA hosted search and discovery service.
