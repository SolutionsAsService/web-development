CSS and components

Styling approaches, preprocessors and component kits.

  • Tailwind CSSA utility-first CSS framework.
  • BootstrapA component and grid framework for responsive sites.
  • SassA CSS preprocessor with variables, nesting, mixins and modules.
  • PostCSSA tool for transforming CSS with JavaScript plugins.
  • Lightning CSSA fast Rust parser, transformer and minifier for CSS.
  • CSS ModulesCSS files whose class names are scoped locally by default.
  • styled-componentsCSS-in-JS that attaches styles to React components using tagged templates.
  • EmotionA CSS-in-JS library with object and string styles.
  • vanilla-extractType-safe CSS written in TypeScript and extracted at build time.
  • UnoCSSAn on-demand atomic CSS engine.
  • Panda CSSBuild-time CSS-in-JS with type-safe styling.
  • Open PropsA set of CSS custom properties for consistent design tokens.
  • RadixUnstyled, accessible component primitives for React.
  • shadcn/uiCopy-in components built on Radix and Tailwind that you own and edit.
  • Headless UIUnstyled accessible components designed for Tailwind CSS.
  • React AriaAccessible UI behaviour hooks and components from Adobe.
  • MUIReact components implementing Material Design and more.
  • Chakra UIAn accessible React component system with style props.
  • Ant DesignAn enterprise-oriented React component library.
  • MantineA React components and hooks library.
  • daisyUIComponent class names layered on Tailwind CSS.
