Make the interface

UI libraries

The layer that turns state into DOM.

  • ReactA component library for building user interfaces from declarative functions.
  • VueA progressive framework with templates and a reactivity system.
  • SvelteA compiler-based framework that turns components into small, direct DOM updates.
  • SolidJSA reactive library with fine-grained updates and a JSX syntax, without a virtual DOM.
  • AngularA full application framework in TypeScript with dependency injection and a CLI.
  • PreactA small, React-compatible alternative.
  • LitA small library for building fast web components.
  • Alpine.jsA light framework that adds behaviour with attributes in your HTML.
  • htmxHTML attributes for AJAX, WebSockets and server-sent events, with the server returning HTML.
  • QwikA framework built around resumability, loading JavaScript only when needed.
  • Ember.jsAn opinionated framework for ambitious web applications, with strong conventions.
  • StimulusA modest JavaScript framework that attaches behaviour to server-rendered HTML.
  • TurboSpeeds up server-rendered apps by swapping page fragments instead of reloading.
  • MithrilA small framework with routing and XHR built in.
  • MarkoA declarative UI language with streaming server rendering.
