Foundations

Web platform

Standards and browser APIs. Everything else compiles down to these.

  • HTMLThe markup language of the web: the structure and meaning of a document.
  • CSSThe style language of the web: layout, colour, type and responsive behaviour.
  • JavaScriptThe programming language every browser runs, standardised as ECMAScript.
  • Web ComponentsBrowser-native custom elements, shadow DOM and templates for reusable components.
  • Service WorkersBackground scripts that intercept requests, enabling offline use, caching and push.
  • WebAssemblyA compact binary format that runs near-native code in the browser and elsewhere.
  • WebGPUA modern browser API for GPU rendering and compute.
  • WebRTCPeer-to-peer audio, video and data between browsers.
  • WebSocketsA persistent two-way connection between a browser and a server.
  • Fetch APIThe standard promise-based interface for making HTTP requests.
  • IndexedDBA transactional database built into the browser for larger client-side data.
  • HTTPThe protocol of the web: requests, responses, headers, caching and status codes.
  • WCAGThe W3C guidelines for making web content accessible.
  • WAI-ARIA Authoring PracticesPatterns and roles for accessible interactive widgets.
  • MDN Web DocsThe reference documentation for web standards and APIs.
  • web.devGuidance and courses on modern web development, performance and PWAs.
  • Can I useBrowser support tables for web features.
