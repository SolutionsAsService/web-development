Languages

What you write the web in, in the browser and on the server.

  • TypeScriptJavaScript with static types, compiled to plain JavaScript.
  • RustA memory-safe systems language used for servers, WebAssembly and many JavaScript tools.
  • GoA compiled language with a strong standard library, common for web services and tooling.
  • PythonA general-purpose language behind Django, Flask and FastAPI.
  • PHPA server-side language built for the web; the basis of WordPress and Laravel.
  • RubyA dynamic, expressive language used on the web mainly through Rails.
  • ElixirA functional language on the Erlang VM, used for concurrent web systems via Phoenix.
  • KotlinA JVM language with server-side, JavaScript and WebAssembly targets.
  • C#The main language of .NET and ASP.NET Core.
  • JavaA long-established JVM language behind Spring and many enterprise backends.
  • DartThe language of Flutter, which can compile to JavaScript and WebAssembly.
